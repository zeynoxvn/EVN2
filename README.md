# 🎓 Cổng Thông Tin & Diễn Đàn Học Tập THCS

Chào mừng đến với hệ thống hỗ trợ học tập trực tuyến dành cho học sinh, tích hợp AI kiểm duyệt nội dung an toàn.

## 🚀 Các tính năng chính:
* **💬 Diễn Đàn Thảo Luận:** Nơi trao đổi bài học, hỏi đáp trực tuyến.
* **🛡️ Hệ Thống Kiểm Duyệt Đa Lớp:** Tự động lọc từ ngữ thô tục, xúc phạm, rác mạng bằng Bộ lọc tĩnh (Rule-based) và Trí tuệ nhân tạo (Google Gemini). 
* **🏆 Bảng Xếp Hạng & Trắc Nghiệm:** (Đang phát triển).

## 🛠️ Cấu trúc hệ thống:
* Giao diện xây dựng bằng **Streamlit**.
* Lưu trữ cơ sở dữ liệu miễn phí qua **Google Sheets** (Google Apps Script).
* Mã nguồn AI và Logic kiểm duyệt được đóng gói sạch sẽ trong thư mục `src/`.

## 📌 Hướng dẫn chạy thử hệ thống:
1. Vào trang web Streamlit đã Deploy.
2. Chọn "Quản trị Kiểm duyệt".
3. Nhập API Key vào cột bên trái và bắt đầu test thử các luồng kiểm duyệt an toàn.
